Дипломный проект. Задание 3: тестирование веб-приложения Stellar Burgers.
Структура проекта
- pages - папка с методами тестирования по POM.
- tests - пакет, содержащий тесты. 
- conftest.py - файл с фикстурами.
- data.py - файл с данными, которые используются в тестах.
- locators - папка с локаторами.
- allure_results - папка с результатами тестирования.
- requirements.txt - файл с библиотеками.
Команды для запуска тестов:
Установка зависимостей
pip install -r requirements.txt

Запуск автотестов без отчета
pytest -v

Запуск автотестов и создание отчета о тестировании в Allure
pytest --alluredir=allure_results

Генерация отчета из результатов тестов 
allure serve allure_results
